# joyban.pe.kr 개발 기획서

## 1. 사이트 방향

`joyban.pe.kr`은 단순 개인 소개 페이지보다, 운영자가 만든 것과 배운 것을 계속 쌓아가는 개인 허브로 개발한다.

핵심 목적은 다음 세 가지다.

1. 개인 프로필과 관심 분야를 한눈에 보여준다.
2. AI, 개발, 프로젝트, 커리어 기록을 게시판 형태로 축적한다.
3. GitHub, Instagram, 외부 서비스, 개인 프로젝트로 연결되는 중심 주소 역할을 한다.

## 2. 사이트 콘셉트

### 한 줄 정의

AI와 웹 개발을 기록하고, 직접 만든 작업물을 정리하는 개인 포트폴리오형 블로그.

### 사용자 인상

방문자는 첫 화면에서 다음 내용을 바로 이해해야 한다.

- 이 사이트의 주인이 누구인지
- 어떤 분야에 관심이 있는지
- 어떤 프로젝트와 기록이 있는지
- 연락하거나 더 볼 수 있는 외부 링크가 어디인지

## 3. 주요 메뉴 구조

현재 구현된 네 개 카테고리를 유지하고, 방문자가 이해하기 쉬운 한글 메뉴명으로 다듬는다.

### AI 이야기

AI 관련 글을 모으는 기술 블로그 영역.

콘텐츠 예시:

- AI 도구 사용 후기
- ChatGPT, Codex, 이미지 생성, 자동화 활용법
- AI 서비스 비교
- 직접 만든 AI 관련 실험 기록
- 업무나 일상에 적용한 AI 활용 사례

### 만든 것들

프로젝트 포트폴리오 영역.

콘텐츠 예시:

- 직접 만든 웹사이트
- 사이드 프로젝트
- 자동화 스크립트
- 디자인 또는 개발 작업물
- 배포 링크와 GitHub 링크가 있는 프로젝트 소개

게시글 기본 형식:

- 프로젝트명
- 한 줄 설명
- 사용 기술
- 주요 기능
- 스크린샷
- 데모 링크
- GitHub 링크
- 배운 점

### 생각정리

생각과 방향성을 정리하는 에세이 영역.

콘텐츠 예시:

- 앞으로 만들고 싶은 서비스
- 개발자로서의 방향
- AI 시대에 대한 생각
- 개인 목표와 회고
- 작업 철학

### 배움노트

학습, 경력, 자기계발 기록 영역.

콘텐츠 예시:

- 공부한 기술 정리
- 자격증, 강의, 책 리뷰
- 개발 환경 세팅 기록
- 문제 해결 노트
- 이력서형 경력 요약

## 9. 화면별 개발 요구사항

### index.html

- 사이트 주제를 명확히 보여준다.
- 카테고리 카드는 게시글 수와 최신 글을 보여준다.
- 모바일에서 카드가 한 줄씩 자연스럽게 쌓인다.
- 프로필 이미지는 임시 이미지가 아닌 실제 이미지 또는 의도된 대표 이미지로 교체한다.

### board.html

- URL의 `category` 값에 따라 제목과 설명이 바뀐다.
- 게시글이 없을 때 빈 상태 안내를 보여준다.
- 관리자 로그인 상태에서는 글쓰기 버튼을 보여준다.
- 페이지네이션은 실제 게시글 수 기준으로 표시한다.

### view.html

- 제목, 작성일, 본문, 첨부파일, 외부 링크를 명확히 보여준다.
- 이미지가 여러 장일 때 읽기 좋은 간격으로 출력한다.
- 관리자 로그인 상태에서는 수정, 삭제 버튼을 보여준다.
- 목록으로 돌아가기 버튼은 현재 카테고리를 유지한다.

### admin_write.html

- 카테고리 선택을 필수로 한다.
- 제목, 본문, 첨부파일, 외부 링크를 입력할 수 있다.
- 이미지 업로드 전 미리보기를 제공하면 좋다.
- 저장 후 해당 카테고리 목록으로 이동한다.

## 10. 추천 디자인 방향

개인 홈페이지지만 작업 기록을 보여주는 사이트이므로, 너무 화려한 장식보다 읽기 쉽고 정돈된 디자인이 적합하다.

추천 방향:

- 흰 배경 또는 밝은 회색 배경
- 검정 계열 본문 텍스트
- 포인트 컬러 1개만 사용
- 카드형 목록은 간결하게
- 본문 가독성을 최우선
- 모바일에서 글 읽기가 편하도록 줄 간격 확보

피해야 할 방향:

- 의미 없는 큰 배너 이미지
- 너무 많은 애니메이션
- 카테고리별로 과하게 다른 디자인
- 본문보다 장식이 더 눈에 띄는 구성
